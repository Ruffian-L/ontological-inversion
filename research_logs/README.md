# research_logs/

Long-form subject logs, one file per subject, `YYYY-MM-DD_title.md`.

How this sits next to the other four record files:

| File | What it is |
|---|---|
| `CHANGELOG.md` | short. every action, newest at top, `We did / We think / Next` |
| `research_logs/` | **long form.** one subject, room to show working and dead ends |
| `runs/` | run cards. structured per-experiment evidence, verdict, exact command |
| `SCOREBOARD.md` | one row per rung, the climb, newest at bottom |
| `RESEARCH_LOG.md` | the narrative index and locked-findings table |

A run card answers *what did this experiment show*. A research log answers *what
did we come to understand, and what did we get wrong on the way*. When an
experiment is small, the run card is enough; when a subject spans several runs and
a change of mind, it earns a file here.
